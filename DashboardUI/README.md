Social Media Streamlit Dashboard

Run the dashboard from the project root:

```bash
python -m streamlit run DashboardUI/app-v1.py
```

Or run from the `DashboardUI` folder:

```bash
cd DashboardUI
python -m streamlit run app-v1.py
```

Place `social_media_user_behavior.csv` in the repository `Dataset/` folder (project root `/Dataset`).
